# Flutter docs first

Before working on a Flutter or Dart task:

1. Identify the relevant topic and **read the current official Flutter documentation** at https://docs.flutter.dev/ . Start from the relevant topic in [official documentation links](references/official-docs.md).
2. For specific widgets, classes, or APIs, verify behavior in https://api.flutter.dev/ . For Dart language and tooling, use https://dart.dev/ .
3. Follow the applicable official guidance rather than inventing conventions or claiming a preference is required by Flutter.
4. If the official documentation does not cover a decision, or cannot be accessed, say so clearly.

Apply this process to planning, implementation, review, debugging, and maintenance of Flutter code.
